# Security Policy

This repository is a hard fork of OBS Studio maintained by based-software.

## Reporting a Vulnerability

Report vulnerabilities by opening a private security advisory at
https://github.com/based-software/obs/security/advisories/new

Please include a short proof of concept or reproduction steps where possible.

For vulnerabilities that also affect upstream OBS Studio, report them to the
OBS Project via https://obsproject.com/discord or security@obsproject.com so
the fix can land upstream as well.
